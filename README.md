# Goce's Retro Portfolio

Welcome to my retro-themed portfolio site! This project showcases my skills in web development and serves as a fun way to learn programming. The site has a nostalgic, pixel-art style inspired by old-school video games.

## Features

- **Retro Design**: The site features a dark background with neon-colored accents and pixel-art buttons, inspired by classic video game interfaces.
- **Sections**: 
  - **About Me**: Learn more about me and my journey into programming.
  - **Projects**: A showcase of the projects I’m currently working on to improve my HTML and CSS skills.
  - **Contact**: A section with custom pixel-art icons (currently placeholders).

## Technologies Used

- **HTML**: Used for the structure and layout of the webpage.
- **CSS**: Used for styling, including creating the retro look with neon colors and pixel-art-style borders.
- **No JavaScript**: The project focuses on HTML and CSS to keep it simple and beginner-friendly.
